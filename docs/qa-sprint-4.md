# Sprint 4 QA Checklist

> Integration & QA Lead validation steps. Execute after all agent deliveries are merged.

## Environment

- Branch: `feat/integration-qa`
- Build: `cargo tauri build` (release) or `cargo tauri dev`
- Frontend: `pnpm build` then serve via Tauri
- OS: Windows (primary), macOS (spot-check), Linux (spot-check)
