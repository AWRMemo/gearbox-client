# ADR-014: v1.0 Release Criteria

## Status
Accepted

## Context
Sprint 20 closes the v1.0 milestone. This document defines the 10 gates that must pass before the `v1.0.0` tag is applied to `main`.

## Release Gates

| # | Gate | Status | Verification |
|---|------|--------|-------------|
| 1 | All non-ignored Rust tests pass | 🔄 | `cargo test --workspace --exclude relay-sync-server` |
| 2 | Server tests 45+ pass | ✅ 47 | `cargo test -p relay-sync-server` |
| 3 | SEC-12-SYNC-METADATA resolved | ✅ | OpaqueBlob v2 default for new accounts |
| 4 | Mobile CI green (iOS + Android) | 🔄 | `ios-build.yml` + `android-build.yml` on GitHub Actions |
| 5 | Paywall functional (UI + logic) | ✅ | `check_paywall_trigger` + `PaywallModal` |
| 6 | E2E tests runnable locally | ✅ | `pnpm test:e2e` against Tauri dev server |
| 7 | Privacy policy published | ✅ | `docs/privacy-policy.md` (Sprint 17) |
| 8 | Known issues document current | ✅ | `docs/known-issues.md` updated |
| 9 | Public repo snapshotted | 🔄 | After `v1.0.0` tag |
| 10 | Crash reporting active (opt-in) | ✅ | Sentry + telemetry module |

## Non-Gates (Deferred to Sprint 21)
- Stripe payment integration (paywall is UI only)
- Creator tier monetization
- Physical-device AI validation
- Embedding CDN fallback + GPU
